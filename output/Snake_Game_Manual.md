## 1. Введение

Добро пожаловать в обновлённую игру «Змейка»! Это классическая аркада, переосмысленная с использованием современных подходов к модульности, графике и пользовательскому опыту.

Игра написана на **Python** с использованием библиотеки **Tkinter** для UI и **Pillow** для работы со спрайтами. Включает:

- Систему рекордов и таблицу лидеров
- Звуковые эффекты (Web Audio-подобный синтез)
- Динамическую сложность (ускорение по мере роста счёта)
- 4 цветовые темы: Dark, Light, Matrix, Ice
- 3 типа бонусов: Золотое яблоко, Снежинка, Магнит
- Систему достижений (ачивок)
- Плавную анимацию движения змейки (интерполяция)
- Тестовый режим через аргумент `--event`

## 2. Цели и правила

### Цель

Набрать как можно больше очков, управляя змейкой и поедая яблоки, избегая при этом столкновений со стенами, границами поля и собственным телом.

### Правила

- Змейка движется непрерывно в выбранном направлении.
- Съеденное яблоко увеличивает длину змейки и даёт **+1 очко**.
- Скорость игры растёт с каждым съеденным яблоком.
- Столкновение с границей, стеной или собственным телом = **Game Over**.
- Бонусы появляются случайно после поедания яблока (шанс настраивается).
- Бонус исчезает, если не успеть его съесть за отведённое время.

## 4. Игровой процесс

Игровое поле представляет собой сетку 20×20 клеток (настраивается). Змейка стартует в центре, её начальное направление выбирается **случайно** при каждом запуске.

Каждый логический шаг змейка перемещается на одну клетку. Визуально движение **плавное** благодаря интерполяции между кадрами.

На поле также расположены **стены** (8 блоков по умолчанию), которые меняют вид в зависимости от темы.


## 5. Бонусы

После съедания обычного яблока с вероятностью **20%** на поле появляется бонус. Время жизни бонуса — **60 тиков**. Перед исчезновением бонус начинает **мигать**.

| Бонус | Файл спрайта | Эффект | Длительность |
| --- | --- | --- | --- |
| 🥇 Золотое яблоко | bonus_gold.png | +5 очков | мгновенно |
| ❄️ Снежинка | bonus_slow.png | Замедление игры | 150 тиков (~15 с) |
| 🧲 Магнит | bonus_magnit.png | Притягивает еду в радиусе 3 клеток | 250 тиков (~15 с) |

### Механика магнита

Пока активен эффект магнита, еда автоматически перемещается на 1 клетку в сторону головы змейки каждый кадр. Как только еда достигает головы — она съедается (+1 очко), и появляется новое яблоко.


## 6. Ачивки (Достижения)

Система достижений мотивирует игрока выполнять разнообразные задачи. Прогресс сохраняется в файле `achievements.json`.

| ID | Название | Описание | Условие |
| --- | --- | --- | --- |
| first_blood | Первая кровь | Съешьте первый бонус | total_bonuses ≥ 1 |
| speed_demon | Демон скорости | Наберите 30 очков за игру | max_score ≥ 30 |
| marathon | Марафонец | Змейка вырастет до 30 сегментов | max_length ≥ 30 |
| bonuses_hunter | Охотник за бонусами | Съешьте 3 бонуса за игру | session_bonuses ≥ 3 |
| veteran | Ветеран | Завершите 5 игр | games_played ≥ 5 |

При разблокировке достижения в центре экрана появляется всплывающее уведомление.


## 7. Начало игры

1. Запустите `python snake_app.py`.
1. В появившемся окне введите имя игрока (или нажмите OK для имени «Аноним»).
1. Змейка появится в центре поля и начнёт движение в случайном направлении.
1. Управляйте змейкой клавишами WASD или стрелками.

## 8. Управление

| Действие | Клавиши |
| --- | --- |
| Движение вверх | ↑ / W |
| Движение вниз | ↓ / S |
| Движение влево | ← / A |
| Движение вправо | → / D |
| Пауза / Продолжить | Space / P |
| Смена темы | T |
| Окно достижений | A |
| Рестарт (после Game Over) | R |

**Важно:** разворот на 180° запрещён (нельзя мгновенно пойти в противоположную сторону).

## 12. Настройки (config.json)

Все параметры игры вынесены в `config.json`. Изменение значений не требует правки кода — достаточно отредактировать файл и перезапустить игру.

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| speed | int | 180 | Начальная задержка шага (мс) |
| min_speed | int | 50 | Минимальная задержка (макс. скорость) |
| width | int | 20 | Ширина поля в клетках |
| height | int | 20 | Высота поля в клетках |
| cell_size | int | 25 | Размер клетки в пикселях |
| score_acceleration | int | 2 | Ускорение за очко (мс) |
| theme_name | str | Dark | Тема по умолчанию |
| bonus_ttl | int | 60 | Время жизни бонуса (тики) |
| slow_effect_duration | int | 150 | Длительность замедления (тики) |
| magnet_effect_duration | int | 250 | Длительность магнита (тики) |
| magnet_radius | int | 3 | Радиус притяжения еды (клетки) |
| bonus_blink_threshold | int | 15 | Порог мигания бонуса (тики) |
| slow_step_penalty | float | 0.05 | Добавка к шагу при замедлении (сек) |
| effect_life | int | 30 | Время жизни визуальных эффектов (кадры) |
| magnet_effect_life | int | 25 | Время жизни эффекта магнита (кадры) |
| test_effect_life | int | 60 | Время жизни тестовых эффектов (кадры) |
| bonus_spawn_chance | float | 0.2 | Шанс появления бонуса (0.0–1.0) |
| wall_count | int | 8 | Количество стен на поле |


## 13. Решение проблем

| Проблема | Решение |
| --- | --- |
| Нет звука | Проверьте настройки звука ОС |
| Игра лагает | Увеличьте `speed` в config.json |
| Сброс рекордов | Удалите `scores.json` — он создастся заново |
| Не запускается | Установите Python 3.8+ и `pip install Pillow` |
| Змейка не отображается | Проверьте наличие PNG в `assets/` |
| Ошибка `TclError: wrong # coordinates` | Обновите `snake_app.py` до актуальной версии |
| Бонус не исчезает | Проверьте `bonus_ttl` и `bonus_blink_threshold` |
